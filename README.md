# Cyber-Threat-Analytics-Platform-with-Incident-Visualisation-System
📊 Cyber Threat Analytics Platform

🚀 Project Overview

This project was completed as part of our internship with Infosys Springboard Virtual Internship 7.0.

Cyber Threat Analytics Platform is an interactive data analytics project designed to analyze cybersecurity threat logs and provide meaningful insights through interactive visualizations. The project uses Power BI to transform cybersecurity data into an easy-to-understand dashboard.

The project demonstrates how data analytics and visualization can be used to understand cyber threats, identify patterns and trends, and support data-driven decision-making.

🗂️ Project Files

Here’s an overview of the files in this repository:

- Team_Members_PPT/ – Individual PPT slides for each team member
- Cyber_Threat_Analytics.pbit – Main Power BI dashboard template
- Team-A-Group-PPT.pptx – Group presentation slides
- Internship_Project_Report.docx – Internship project report
- README.md – Project overview and documentation

🚀 Key Features

📊 Cyber Threat Visualization

Provides interactive visualizations of cybersecurity threat data using Power BI.

🔍 Threat Analysis

Analyzes different types of cyber threats and security-related activities.

📈 Trend Analysis

Helps identify patterns and trends in cybersecurity incidents over time.

🧠 Interactive Dashboard

Allows users to explore cybersecurity data through interactive charts and visualizations.

📋 Data-Driven Insights

Transforms raw cybersecurity logs into meaningful information for analysis and decision-making.

🛠️ Tools & Technologies

- Power BI – Dashboard creation and data visualization
- Power Query – Data cleaning and transformation
- Microsoft Excel / CSV – Data handling and preprocessing
- GitHub – Project repository and version control

📊 Project Workflow

Data Collection – Collected cybersecurity threat log data from the available dataset.

Data Cleaning & Preprocessing – Cleaned and transformed the raw data using Power Query.

Data Analysis – Analyzed cybersecurity events, threat types, and related patterns.

Visualization / Development – Created an interactive Power BI dashboard with charts and visualizations.

Insights & Interpretation – Studied the visualized data to identify meaningful cybersecurity insights and trends.
